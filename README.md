# Analiza-i-wizualizacja-danych---Berka-Dataset
Dokonanie podstawowej analizy i wizualizacji danych pozyskanych z Berka Dataset.

Niniejszy projekt wykonany w programie Power Bi Desktop polega na załadowaniu i oczyszczeniu danych, utworzeniu relacji, przygotowaniu modelu danych oraz dokonaniu analizy transakcji klientów wraz z wizualizacją statystyk.
